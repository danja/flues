## **Euclidean Gravity Arpeggiator**

### Core Concept
Multiple "playheads" orbit between held notes (gravity wells), with each playhead following a different Euclidean rhythm pattern. The spatial properties of your held notes determine the Euclidean parameters.

### Grid Layout (8x8)

**Main area (8 columns × 6 rows)**: Isomorphic scale-locked layout
- Any button held = gravity well created
- Pitch determined by isomorphic position
- Intensity (LED brightness) shows gravity strength

**Top 2 rows**: Control zones
- Row 8: Euclidean density (0-7 pulses per cycle)
- Row 7: Cycle length (4, 6, 8, 12, 16 steps, etc.)

### Playhead Behavior

**Number of active playheads** = number of held notes (up to 4-6 for clarity)

Each playhead:
1. **Follows a unique Euclidean pattern** based on its associated gravity well's position
2. **Bounces/orbits between gravity wells** with velocity influenced by distance
3. **Triggers the note** of whichever gravity well it's currently nearest when a Euclidean pulse occurs

### Euclidean Parameter Mapping

**From held note positions:**

- **Vertical position (row 1-6)** → Euclidean pulse count
  - Row 1 = E(2,8), Row 2 = E(3,8), ... Row 6 = E(7,8)
  
- **Horizontal position (column A-H)** → Pattern rotation offset
  - Column position rotates the Euclidean pattern 0-7 steps
  
- **Distance between notes** → Playhead travel time
  - Closer notes = faster transitions
  - Distant notes = slower, more suspended movement

### Performance Techniques

**1. Single Note Hold**
- Creates one playhead with one Euclidean pattern
- Simple rhythmic melody on that note
- Move finger up/down to change rhythm density
- Move left/right to rotate pattern phase

**2. Two Notes (Interval)**
- Two playheads bouncing between two pitches
- Creates interlocking Euclidean patterns
- Distance controls tempo of alternation
- Vertical positions create polyrhythm (e.g., E(3,8) against E(5,8))

**3. Three+ Notes (Chords)**
- Multiple playheads create complex polyrhythmic arpeggios
- Each note's vertical position = its Euclidean density
- Triangle shape = three different Euclidean patterns interweaving
- Square shape = four-voice polyrhythm

**4. Dynamic Repositioning**
- Slide a held note vertically = morph rhythm density in real-time
- Slide horizontally = rotate phase
- Add/remove notes = change number of voices
- Gravity wells pull playheads, creating musical tension/release

### Top Row Controls (Row 7-8 options)

**Option A - Global parameters:**
- Column 1-4: Master clock division (1/4, 1/8, 1/16, 1/32)
- Column 5-8: Global cycle length (8, 12, 16, 24 steps)

**Option B - Per-playhead modifiers:**
- Column 1-2: Gravity strength (weak/strong attraction)
- Column 3-4: Playhead physics (bouncy/smooth/chaotic)
- Column 5-6: Velocity curves (soft/hard triggers)
- Column 7-8: Note length (staccato/legato)

### Visual Feedback (LED Grid)

- **Held notes**: Bright, pulsing with their Euclidean pattern
- **Playheads**: Moving lights traveling between gravity wells
- **Active pulses**: Flash when note triggers
- **Pattern preview**: Dim indicators showing Euclidean structure

### Musical Example

Hold three notes forming a minor triad:
- Root (row 3, col 2) → E(4,8) = [x..x..x.] 
- Minor 3rd (row 5, col 4) → E(6,8) = [x.x.x.x.x]
- Perfect 5th (row 2, col 6) → E(3,8) = [x...x...]

Three playheads circulate, creating a complex polyrhythmic arpeggio where:
- 4-against-6-against-3 pulses
- Phase relationships constantly shifting
- Gravity pulls create accelerando/ritardando between notes
- Result: organic, evolving pattern that stays in tune

### Advanced Feature: Gravity Strength

- **Pressure sensitivity**: Harder press = stronger gravity well = playheads linger longer
- **Multi-touch**: Second finger on same button increases gravity
- Creates expressive control over which notes are emphasized

This combines guaranteed harmonic consonance (isomorphic + scale-lock) with mathematically interesting rhythms (Euclidean) and organic, physical movement (gravity wells).
