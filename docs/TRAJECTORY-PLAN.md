I want a new experiment, a synth with its oscillator based on the movement of a bouncing point inside a polygon. Call it Trajectory. Trajectory will be implemented using the basis of experiments/disyn with the oscillator section replaced with the following. As well as the existing blocks of the Disyn synth it will have an added small oscilloscope view of the output waveform.

It will have parameter variables: number of polygon sides 3-12, angle from the center point to a starting point on one of the sides, start angle. Each of these will have a corresponding control knob in the UI. Another variable, velocity will be coupled to the note given as input, scaled such that the output will be an audio tone. The two angles will be controlled by knobs. The oscillator value at an instance in time is taken from the position of the point on the y axis. Its amplitude should be scaled to give best audio output.
